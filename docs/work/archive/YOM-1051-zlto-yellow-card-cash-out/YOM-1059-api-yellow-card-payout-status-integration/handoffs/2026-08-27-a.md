## What Was Done

- Replaced the Yellow Card webhook shell with exact raw-body HMAC-SHA256 authentication.
- Added required-header, Unix timestamp tolerance and constant-time signature validation.
- Added the confirmed webhook payload and centralized provider-status mapping shared with polling.
- Correlated events by signed Yoma payout id and verified the provider transaction id.
- Added volatile event replay suppression and retry-safe marker removal after processing failure.
- Routed authenticated outcomes through the existing payout business process:
  - Processing persists against Payout.Transaction.
  - Completed commits ZLTO, marks Reward.Transaction Processed, updates Treasury and completes the payout.
  - Failed, Cancelled and Expired release ZLTO, mark Reward.Transaction Released and close the payout.
- Hardened concurrent, duplicate and out-of-order event handling without permitting terminal-state regression.
- Hardened an ambiguous ZLTO reservation response: it remains active and blocks another payout until
  the reservation threshold, because ZLTO cannot retrieve it by Yoma's external reference.
- Added non-secret webhook configuration placeholders; no Helm, environment-secret or migration changes were made.

## Gotchas

- HMAC verification depends on the exact UTF-8 request body; never reserialize JSON before verification.
- The replay marker is deliberately removed after failed business processing so IXO's retry is not suppressed.
  Persisted payout/reward states and the payout distributed lock remain authoritative.
- The five-minute reconciliation schedule remains the fallback for missed webhooks and partial failures.
- PayoutRewardReservationExpirationInMinutes is fixed at 1800 minutes: IXO keeps an unconfirmed payout
  resumable for 24 hours and bounds post-confirmation processing at approximately six additional hours.
- Current timeout controls are deliberately separate: ZLTO payout HTTP 30 seconds, IXO HTTP 60 seconds,
  payout lock lease five minutes, webhook replay tolerance five minutes and ZLTO reservation 30 hours.
