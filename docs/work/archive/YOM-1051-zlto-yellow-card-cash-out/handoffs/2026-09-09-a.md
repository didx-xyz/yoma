## Gotchas

- The developer-managed PostgreSQL instance configured in the local API settings is authoritative for
  local API testing; the Docker Yoma PostgreSQL database is not the database used by the debugger.
- WorkOS verifies the supplied email address and IXO confirmed there is no Test bypass or fixed OTP.
- Do not send a mocked terminal webhook for a payout that also exists in IXO Test. Doing so can commit
  or release the ZLTO reservation while IXO still considers the payout active.
- A short-lived hosted session may be refreshed while the payout is active. The session expiry does
  not expire the underlying payout or its reservation.
- Hangfire reconciliation updates `DateLastReconciled`; isolate webhook replay checks with immediate
  before/after snapshots so a scheduled reconciliation run is not mistaken for duplicate processing.
- No secrets, hosted-session tokens or test-account credentials are recorded in this handoff.
