## Gotchas

- **Missing DOB/gender/country/names opens the global "Complete your profile" dialog** over the page (`isUserProfileCompleted`). That is why the gate test drops `email`: it is the only cash-out field the global check ignores.
- **The cash-out dialog has two buttons named "Close"**: the ✕ (`aria-label`) and the text button. Select the text one with `locator("button", { hasText: "Close" })`.
- **Treasury pool cannot be reset.** The admin Treasury form cannot save while the payout pool is USD 0, because the validator requires > 0. A test that saves cannot put the seeded 0 back. A positive pool would also turn test 5's "paused" into "funds available" for every run after it. So do not save the Treasury on a local stack you test cash-out on.
- **Tests 1–2 assert absence** (`toHaveCount(0)`). Each first confirms the overlay applied (ledger shows 500 / the link is present), so they cannot pass on a missed route.
- `--no-deps` skips the ~10 min warm-up + sign-in when iterating on one file. It needs `e2e/.auth/*.json` from an earlier run.
