## Trade-offs / Release Checks

- Matching remains best effort, not semantic inference. Unknown/ambiguous labels
  are omitted. Acronyms such as CSS will no longer match solely because they occur
  in parentheses; a canonical match or separately reviewed mapping is needed.
- Existing sync hashes the mapped update request, including Skills. A changed
  mapping can therefore trigger an update on the next pull even if source payloads
  are unchanged. Opportunity update replaces the skill list, including removal of
  mappings that now resolve to nothing. Validate this on Stage for all three callers.
- No historical credential repair is included or implied.
- Planned month-end release alongside Umuzi/cash-outs, explicitly not a hotfix.
- Umuzi Stage has imported four opportunities. One failed date/commitment validation;
