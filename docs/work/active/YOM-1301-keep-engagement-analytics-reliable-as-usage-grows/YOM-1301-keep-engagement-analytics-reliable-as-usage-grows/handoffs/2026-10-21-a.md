## Gotchas

- Full-history totals are not capped to the 52 displayed weeks.
- Sunday rolls into the following Sunday's bucket, matching historical behavior.
- Do not replace integer day-number bucketing with timestamptz plus an interval: session daylight-saving transitions can move an early-UTC event into the wrong calendar day. The regression at 2024-09-28 00:30 UTC with Pacific/Auckland reproduces this trap.
- Completion eligibility uses DateCompleted and includes missing dates; chart buckets continue to use DateModified.
- Demographics and skill occurrences count completed participation rows, not distinct youth. Weekly skills remain distinct by skill ID. Cumulative organizations remain grouped by name, not ID.
- Equal-count top skills now sort by name then ID rather than an unspecified source order.
- SQL still has work proportional to history. This removes per-completion application buffering; it does not remove database load, concurrent-request memory or other potential OOM causes.
- Repeated rolled-back bulk fixtures need refreshed planner statistics. An interrupted runner can leave its server-side query running; cancel only the owned disposable query/connection before rerunning.
- Production OOMs were observed at this endpoint, but the separate overnight OOMKills remain unconfirmed; do not claim their cause or complete resolution.
