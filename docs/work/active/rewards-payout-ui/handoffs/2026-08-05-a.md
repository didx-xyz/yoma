## Gotchas

Carry these verbatim — they have each cost time already.

- **Three Treasury figures, never conflate**: `payoutPool` (allocation) · `payoutBalance` = pool − cumulative (**COMPLETED-ONLY, not capacity**) · `payoutBalanceAvailable` = balance − pending (**THIS is capacity**).
- **`PATCH /treasury` and `PATCH /organization` are FULL REPLACEMENTS.** Omitting a pool clears it. Always send the current value of everything you are not changing.
- **Server validation failures carry no field name** — `PropertyName` is discarded, so per-field mapping is message-text matching.
- **Permissions failures return HTTP 401, not 403**, so `ApiErrors` says "your session has expired" for what is actually a permissions problem.
- **Wallet: `balance` / `available` / `total` are NULLABLE** (null when the provider is offline); `pendingPayout` / `pendingRewards` are not. **Branch on `null`, NOT on `zltoOffline`** — two signals for one state will drift. `null + 5` is `5` in JS, and `0` is a legitimate balance, so neither arithmetic nor truthiness is safe.
- **`total` = `available + pendingRewards`.** It never included `pendingPayout`; an earlier note claiming otherwise was wrong.
- **Rewards have NO available-balance equivalent and never will** — they allocate at schedule time. Do not add one by analogy with Treasury.
- **T4 must show Treasury ZLTO REWARD figures, not USD payout figures.** Pulling `payoutBalanceAvailable` onto a referral surface is a category error.
- **The `?mock=` dev aid is committed and must be removed before merge** — `lib/treasury/treasuryMockScenarios.ts` plus the three `⚠️⚠️ MOCK SCENARIOS` blocks in `pages/admin/treasury/index.tsx` (and `MOCK_PARAM`).
- **`OrganizationRewardSummaryRow.tsx:103`** — `NoImage` fallback is 60px against a 30px logo.
