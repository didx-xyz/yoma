## Gotchas

- `SearchInput` blanks its placeholder on focus, so `getByPlaceholder` locators die after `fill`;
  use `getByRole("searchbox")`.
- react-select option labels can read "01 Job" for "01 - Job"; `links.spec.ts` matches on words.
- The Keycloak theme's `v-otp-input` auto-submits at 6 digits; test numbers use 4, real codes 6.
- Dummy SMS sender fails 20% of sends at random and the provider caps 10 sends per source IP per
  hour across all numbers — a loop of real-number tests exhausts it; rows live in
  `phone_message_token_code` (keycloak-pg).
- After a successful verification a new code can be requested immediately (consumed codes are no
  longer "ongoing"); the 5-minute wait only applies while an unused code is live.
