## What Was Done

The Dev reset (CICD `workflow_dispatch` on this branch) failed in the Keycloak post-install hook:
`keycloak-users: Import failed` after `partialImport` returned 403.

Cause: CI sets `postInstallHook.ref` to the branch SHA, so the hook runs this branch's
`src/keycloak/scripts/users.sh`. That script now imports users through
`POST /admin/realms/yoma/partialImport`, which needs `manage-realm`. The hook still signed in as
the runtime account `sa-yoma-api` (`keycloak-users` / `keycloak-user` and
`SA_YOMA_API_PASSWORD`), which only has `view-users`, `manage-users` and `view-realm`
(`src/keycloak/exports/03-master-users.yaml`). Compose was already switched to the bootstrap admin;
Helm was not.

Fix: `helm/keycloak/values.yaml` now gives the hook `KC_ADMIN_USER` / `KC_ADMIN_PASSWORD` from the
`keycloak-admin` secret (`user` / `password`), the bootstrap admin in the `master` realm. This
matches `src/api/docker-compose.yml`. `sa-yoma-api` keeps its roles.
