## Gotchas

- Local AttributeNames never included the removed extra attribute. That column alone cannot prove a remote preset is clean; new preset creation uses and validates the new adapter definition. Inspect replacement signed claims during rollout verification.
- Existing domain credential IDs may be local journal IDs. Passing them directly to new Replay can conflict with the recovered wallet ID.
- Missing/duplicate/unconfirmed historical attempts stop the script for review. No guessing, deletion of audit mappings or blind requeue of ordinary Pending/Error rows.
- Replay retains the issuance date but rebuilds attributes through the current issuance process. It does not clone an immutable old payload.
- The original Prod provider-cutover migration remains unchanged. This manual Stage operation must not be added to it.
- Cache population/writes use a five-minute lease with a thirty-second acquisition timeout. No unlocked fallback; the existing lease is not renewed or fenced against overlong execution. A request already holding a schema may complete with that snapshot. Old replicas retain their memory-cache behavior until rollout completes.
- Domain model reconstruction now runs per read, including existing schema-protection reconciliation. Provider schema retrieval remains cached; lookup services retain their existing cache behavior. No shared cache service changes or new dependencies.
