- Updated Local initialization, placeholder settings and the environment guide. The initializer moves only the integration-owned sections and preserves unrelated settings.
- Updated the Yoma realm import for the assertion callback and the runtime operator permission. No mono source, Helm, deployed configuration or database changes.
