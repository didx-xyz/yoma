## Gotchas

- Ticket ids here are **ixo-world** Linear ids and can collide with DIDx `YOM-` ids.
- This repo is public. Keep Auth Hub internals (security posture, private file paths beyond what
  the contract needs) out of these docs; review the epic README with that in mind before pushing.
- Local prod builds need `CI=true` (else `/marketplace/[country]` hits the API at build) and a
  build-time `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` (else the client crashes on env validation).
  `next start` needs the hoisted binary at the repo root `node_modules/.bin`.
- The spike ran on Node 26.7; the repo pins 24. Not expected to matter, not verified.
- With `scope=session` the hub returns no email — nothing in the Yoma flow may rely on it.
