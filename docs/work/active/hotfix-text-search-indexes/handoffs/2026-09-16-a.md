## Gotchas

Concurrent builds commit individually and can wait on old transactions or consume resources. Run one migration executor; avoid peak-load deployment, allow sufficient command time, and inspect invalid-index state on failure. Retry deliberately rebuilds new indexes already created by that incomplete migration. Existing indexes are never targeted. Do not remove pg_trgm in a rollback.
