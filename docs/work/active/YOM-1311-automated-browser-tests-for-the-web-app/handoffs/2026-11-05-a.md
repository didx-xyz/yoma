## Gotchas

- The wizard's date inputs commit on blur (`fill` then `Tab`); skills search is debounced 1 s and
  needs ≥3 chars; keywords need Enter.
- The verifications row id is per (opportunity, user), so parallel runs on the same org never
  collide; titles carry a per-run token (`E2E <base36 time>`).
- Approval is blocked while an *older* pending submission from another user exists on the same
  opportunity — fresh opportunities per run avoid the seeded pending rows on fixtures 04/05.
