## Gotchas

- The API title-cases names: "User E2E" is stored as "User E2e". Use single-word test values.
- `/user/settings` response: `groups[].items` can be null on a group that only has sub-groups.
- The discovery results card is a `div`, not `<article>`; the CTA `<a>` is the only
  `/opportunities/<uuid>` link on the page (the drawer links to `/opportunities/discover`).
- Marketplace: `#letsGoButton` routes by alpha-2 code of whatever country react-select picked
  for "South Africa"; assert the pattern, not `ZA`.
- Wallet locally: "Your wallet is still being set up" — no `#wallet-balance`; use
  `#wallet-products-heading`.
- Multi-route tests on a cold dev server with 3 workers need `test.slow()`; CI (prod image) does
  not compile per route.
