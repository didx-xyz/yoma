## Gotchas

- Coverage numbers describe **loaded client modules only**. A route no test visits is simply
  absent, not 0 %. Server code (`getServerSideProps`, `pages/api`, `server/`) is never counted.
- Next.js reverts `devtool` changes in dev, so do not try `config.devtool = "source-map"` in
  `next.config.mjs` — it is silently undone with a warning.
- Under coverage, a cold dev-server compile + hydration after the Keycloak callback can exceed
  20 s. The 30 s wait in `loginViaKeycloak` covers it; if it recurs elsewhere, warm the route
  first rather than raising global timeouts.
