## Gotchas

- `/etc/hosts` needs `127.0.0.1 keycloak` (browser is redirected to `http://keycloak:8080`).
- Stacks seeded before this change lack the fixed ids: the org-admin journey 404s until
  `docker compose down -v`.
- `page.waitForURL` after Keycloak: capture the Keycloak origin **before** clicking submit — the
  redirect can complete before `click()` resolves, and waiting to leave the *current* origin then
  never resolves (cost one 10-minute timeout this session).
- `/organisations/{id}/opportunities` has no `#results` container; `/organisations` does.
- Two `region`s are named "Wallet" on `/yoid`; use `section#wallet`.
- `CI` is set in Jason's shell → retries/single worker locally unless `--retries=0`.
- `ReferralWelcomeIntro` renders `btnSignIn_referralsIntro`; if it is ever rendered twice on one
  page the id will collide — pass an id through if that happens.
