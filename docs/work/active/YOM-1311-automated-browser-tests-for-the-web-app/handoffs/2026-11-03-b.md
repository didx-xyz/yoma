## Gotchas

- Phone OTP: 3 sends per code type per hour on the test number → `phone.spec.ts` at most 3×/hour
  locally. CI seeds fresh, never hits it. `docker compose down -v` resets.
- `kc_locale` query param does nothing on this realm; use the site switcher (`ui_locales`).
- intl-tel-input loads utils from jsDelivr and geo-IP from ipapi.co at runtime; `requestOtp`
  awaits its `promise`. Offline CI will fall back to ZA (catch → `za`) but the CDN import must
  succeed or `isValidNumber` is undefined — watch for this when the CI job is wired.
- Phone-only users have no profile → "Complete your profile" dialog on every login; the reset
  test clears cookies instead of using the UI logout.
- Toasts persist across logout and overlay the Login button.
