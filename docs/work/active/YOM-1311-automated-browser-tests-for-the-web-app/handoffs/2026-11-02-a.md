## Gotchas

- `/etc/hosts` needs `127.0.0.1 keycloak` on any machine running the test (and on the CI runner)
  because the browser is redirected to `http://keycloak:8080`.
- Chromium must be installed once: `mise x -- pnpm exec playwright install chromium`.
- Duplicate ids in the app (`#btnSignIn` twice, three `label[for="userMenu-drawer"]`) break
  strict-mode locators — use roles/titles. Worth fixing in the app at some point; not done here.
- The post-login "Choose your settings" modal appears on every fresh login of the seeded user
  (`User_Settings_Configured` is not seeded). Tests for signed-in surfaces will have to dismiss
  it (button "Skip for now", `components/Global.tsx`) or seed the setting.
- `src/api/cicd/scripts/postgressql-init/post.sql` comments the test password as `P@ssword1`; the
  real seeded value is `P@ssword12` (`src/api/docker-compose.yml`, `keycloak-users`).
- Running with `CI` set in the shell turns on `retries: 2` and `workers: 1`; this machine's shell
  had it set, which is why early runs showed `retry2` in result folder names.
