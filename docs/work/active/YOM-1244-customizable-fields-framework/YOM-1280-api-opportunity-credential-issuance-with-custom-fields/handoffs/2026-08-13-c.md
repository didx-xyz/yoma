## Gotchas

- Existing Skills require legacy normalization; custom-field credentials do not exist historically and use the structured format from inception.
- The exact provider schema version remains authoritative for mappings. A missing schema or required mapped attribute is corruption and intentionally fails; a missing optional attribute is omitted.
- Scalar `itemsDisplay` are null; complex attributes return a list. Web renders the API response and never parses signed provider JSON.
- For complex attributes, `itemsDisplay` is authoritative. The comma-and-space joined `valueDisplay` is display-only because an individual label may itself contain commas.
- Runtime validation used `Opportunity|Default:1.0` JWS credentials and `YoID|Default:1.0` ACR credentials.
  A null test-user Education value issued and rendered as `n/a`; configured date-only values rendered as `yyyy-MM-dd`.
