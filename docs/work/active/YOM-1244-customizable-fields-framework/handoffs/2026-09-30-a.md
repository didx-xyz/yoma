## Gotchas

- **`validationRegex` is .NET syntax.** Compile it only through `toEcmaScriptPattern`, never
  `new RegExp(definition.validationRegex)` directly.
- **Opportunity dates are end-of-day / start-of-day UTC.** Label them with `timeZone: "UTC"`, as
  `fmtDate` in `opportunityTypeTheme.tsx` does. Local time rolls a deadline into the next day
  east of UTC.
- **Editor, edit mode:** jumping steps from the sidebar opens "unsaved changes". "Continue
  without saving" DISCARDS the in-memory edits (e.g. a type change). Next only moves on; the save
  happens at Preview → Submit.
- **Editor, create mode:** the sidebar stays locked until each step validates.
- **After sign-in** a "Choose your settings" modal covers the page until skipped. Browser scripts
  must dismiss it before clicking anything.
- **Browser tooling:** `/tmp` is wiped on WSL restart. Re-download the Chrome for Testing headless
  shell and drive it from a small CDP daemon; see the `web-tooling-via-mise` memory.
