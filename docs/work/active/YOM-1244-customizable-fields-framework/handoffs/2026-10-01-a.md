## What Was Done

Jason: "make the experimental pages the actual pages (use kill-switch)".

- **The release kill-switch `CUSTOM_FIELDS_ENABLED` now picks the detail layout:**
  - on (as it is): `/opportunities/{id}`, `/organisations/{org}/opportunities/{id}/info` and
    the editor's step-8 Preview render the round-7 tabbed layout;
  - off: all three render the classic two-column layout, unchanged.
- **Two chokepoints, no per-surface flags:**
  - `OpportunityPublicDetails`: `layout` now defaults to
    `CUSTOM_FIELDS_ENABLED ? "tabbed" : "classic"`. The public page and the Preview pass no
    layout, so both follow the flag.
  - `info.tsx`: its existing body is now `OpportunityInfoClassic`. The page component renders
    `OpportunityAdminInfo` (moved out of the old experimental route into
    `components/Opportunity/TabbedDetails/OpportunityAdminInfo.tsx`) when the flag is on. Same
    props, same server-side data.
- **The temporary routes are gone:** `pages/opportunities/[opportunityId]/experimental.tsx` and
  `pages/organisations/[id]/opportunities/[opportunityId]/info/experimental.tsx`.
  `features/discovery/lib/detailHref.ts` links to `/opportunities/{id}` again.
- **Renames, since "experimental" is now the live layout:**
  - `components/Opportunity/Experimental/` → `components/Opportunity/TabbedDetails/` (git mv);
  - layout value `"experimental"` → `"tabbed"`.

- **Admin info header:** "Manage opportunity" moved to the right end of the actions row (stats
  first). Its menu opens leftwards from the button, so on the left edge it ran off the card
  (Jason). Checked at 1440 and 390: the menu stays inside the viewport.
