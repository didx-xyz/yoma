## Gotchas

- **Recreate the local Yoma DB after pulling this batch** — the unreleased CF migration was
  edited in place; an old volume lacks the new columns. Postgres must run `postgis/postgis`.
- **`PATCH /user` is a full replacement** and omitted location fields CLEAR the place: every
  profile save must resend it (`UserProfileForm` and `userPreferencesLive` both do).
- **Coordinates are `[longitude, latitude]`** on the wire; web holds `{ latitude, longitude }` —
  convert only through `toApiCoordinates` / `fromApiCoordinates`.
- **Search `countries` is objects now.** Never post a GUID array to `/opportunity/search*` —
  go through the search services (`toSearchFilterPayload`). `OpportunitySearchFilterCriteria`
  (pickers) keeps its GUID list.
- **Seeded Jobs can't be saved by an admin** until Salary disclosed and Minimum qualification are
  filled — by design of the seed, not a web bug.
- Local Keycloak: the seeded test users log in through the UI; the redirect host is
  `keycloak:8080`.
