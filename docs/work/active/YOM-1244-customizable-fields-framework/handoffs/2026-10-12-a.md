## Gotchas

- **The key constants must match the API exactly.** `money.ts` and the filter rows compare with
  `===`. A key that differs only in case gives no error, just missing pay or a dropped row.
- **The CSV samples are copies of the API's.** Copy them again when Adrian changes them.
- **The opportunity update replaces the provider fields.** Any new editor path that builds a
  request must carry them, or a save clears them.
- **`["countries"]` is a shared query key** used both with and without Worldwide (pre-existing).
  New code that needs only specific countries uses `["countries", "specific"]`.
- **A manual location on a non-Entrepreneurship completion is rejected** by the API. Keep the
  completion form's location behind the type check.
