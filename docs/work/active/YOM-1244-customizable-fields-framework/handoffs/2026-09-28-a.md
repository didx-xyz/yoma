## What Was Done

- Kept the existing optional `EducationId` on User and UserProfile. All five existing Education lookup IDs are retained; only Tertiary is renamed to "Tertiary (Qualification not specified)". The existing Primary, Secondary, No formal education and Other names and casing remain unchanged.
- Added six Tertiary qualification rows ("Tertiary - Certificate", Diploma, Bachelor’s Degree, Honours Degree, Master’s Degree and PhD) to the consolidated CF configuration migration. The new qualifications consistently use a plain hyphen; none has trailing punctuation.
- Updated both Keycloak realm-export Education option lists to the same eleven values. The realm import files configure options; they do not migrate existing Keycloak user attributes.
- Expanded the isolated CF migration fixture/assertions to check the final lookup and retained IDs. Build and the database-independent migration-shape test pass; isolated PostgreSQL migration execution is still pending.

## Decisions

- Education remains an optional core User profile field, not a new custom field or a new user column.
- Job Minimum Qualification will reuse this lookup when Job custom-field definitions are introduced; it is not an automatic phase-one eligibility gate.
- New YoID credentials consume the updated lookup names through existing user data; issued credentials remain unchanged.
