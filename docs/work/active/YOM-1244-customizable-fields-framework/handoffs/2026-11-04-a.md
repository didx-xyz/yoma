## Gotchas

- **Every Job in the seed is "Permanent"** — post.sql's required-definition loop pins
  `JobEmploymentType` to `Permanent` for the ~240 random Jobs too. A filter test therefore has to
  narrow to the fixtures first; `q="- Job"` returns exactly 01, 02, 05, 06, 21, 22 (random titles
  never contain " - Job"). Absence is proven by 06 and 21 ("incomplete partner-like", all
  custom-field values deleted), presence by the other four.
- `01 - Job` is the only row with `JobSalaryMinimum` (1000) and `JobSalaryDisclosed=true`; chip
  labels are "Minimum Salary: From 1000" and "Salary Disclosed: Yes".
- "Clear filters" also clears `q` and `type`, so the page returns to the home rails — there is no
  `#hdrDiscoveryResults` afterwards; assert the "Featured" region instead.
- Both the desktop `FiltersDialog` and the mobile `FiltersSheet` are in the DOM
  (`hidden md:contents` / `md:hidden`); `getByRole("dialog", { name: "Filters" })` resolves to
  the visible one, a CSS `dialog[aria-label="Filters"]` does not.
- Schema pages: locally `NEXT_PUBLIC_ENVIRONMENT=local` turns on the in-browser mock
  (`credentialSchemaAdmin.ts`), whose fixtures (`Opportunity|Job|Placement`, …) differ from the
  API seed. The spec sets `yoma.schemaMockMode=live` in an init script; CI's production build has
  no mock at all, so both read the live list. The local API does reach the Aries CloudAPI test
  tenant (`appsettings.Local.json`), which is what makes the live read possible.
- Schema type description for YoID is "Yoma Member (YoID)", not "YoID"; the Job schema has 4 locked
  system rows + 19 editable mappings = `propertyCount` 23.
- react-select option typing: "Opportunity" + Enter picks `MyOpportunity` (first substring match);
  the spec clicks `getByRole("option", { name, exact: true })` instead.
- Playwright's bundled chromium is the only browser installed; `npx playwright cli open` needs
  `--browser=chromium` (it defaults to the `chrome` channel). A playwright-cli session cannot set
  `localStorage` on `about:blank` — navigate to any page first.
