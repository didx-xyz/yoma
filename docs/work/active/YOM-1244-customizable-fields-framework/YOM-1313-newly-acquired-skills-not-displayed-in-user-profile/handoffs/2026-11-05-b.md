## Decisions and Evidence Limits

- Normal opportunity updates preserve retained mappings: RemoveSkills removes deselected skills and AssignSkills skips existing rows. Routine edits do not reset mapping creation dates.
- Current rows cannot prove all historical mappings or exclude explicit removal/re-addition. Do not present the excluded 60,798 as individually proven later additions or as confirmed regression losses.
- The audit compares current mappings, so its missing count can remain nonzero after an approved repair is complete. It must not be used as a blanket instruction to award skills.
- No completion, reward, treasury or credential replay was performed. Existing skill rows and financial data were not repair targets.
