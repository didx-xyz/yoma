## What Was Done

- New card fact `education` in `src/web/src/features/discovery/lib/cardFacts.ts`: Job priority is
  now `employment · education · date · effort · a11y*` (the BA's R19 order — education right after
  the employment line). Text `"<name> required"` ("Matric required"), tooltip name
  `Minimum education`, value the lookup name. Keyed on the protected `JobMinimumQualification`.
- The field's value is an Education lookup **id**, not an option key, so `cardFacts` takes a fifth
  argument `educations: { id, name }[]` and labels through it. No name in the list (not loaded
  yet, retired id) → no fact; never a raw id. Absent on the Job → no fact.
- `useDiscoveryLookups` gains `educations` (same cache entry the Personalize wizard already uses,
  `["discovery","lookup","educations"]`, `staleTime: Infinity`); `OpportunityCard` and
  `OpportunityRow` pass it. Icon `IoSchoolOutline` in `FACT_ICONS`.
- Tests: `cardFacts.test.ts` (position, text/tip, lookup-missing, id-missing, field-absent);
  `e2e/youth/discovery-filters.spec.ts` new journey — on the salary URL (one result, `01 - Job`)
  the fact button reads `"<first Education by name> required (Minimum education: …)"`, matching the
  seed (`post.sql` gives every complete Job the first Education by name).
