## What Was Done

First pass at custom-field filtering on the opportunity search.

- **Models** — `CustomFieldFilterOperator` enum and the `CustomFieldFilter` interface
  (`key`, `operator`, `value?`, `valueTo?`, `values?`), plus
  `customFields?: CustomFieldFilter[] | null` on `OpportunitySearchFilterBase`.
- **Public search page** — `customFields` threaded through the full URL lifecycle: parsed from the
  querystring as JSON, added to `isSearchPerformed`, the `searchFilter` memo, the react-query key
  and the `searchOpportunities` call, and serialised back out in
  `getSearchFilterAsQueryString`. Definitions fetched with
  `useOpportunityCustomFieldDefinitionsQuery` keyed on the selected types and passed to the filter
  modal.
- **`OpportunityFilterVertical`** — an operator-matrix-driven block rendered inline at the bottom of
  the modal: an operator `<select>` per definition plus a type-appropriate value control
  (text, date, boolean select, option buttons, or two inputs for `Between`), merged into the submit
  payload with empty clauses filtered out.

## Known gaps (all found and fixed on 2026-08-11)

The payload was **not** verified against a running API in this session, and most of what follows
would have failed at request time:

- Option clauses submitted the option **id** instead of the **key** → `ValidationException`.
- Option + `Equals` submitted `values` instead of the scalar `value` → `ValidationException`.
- `AllOf` was offered for single-select options → `ValidationException`.
- `GreaterThanOrEqual` / `LessThanOrEqual` / `AnyOf` missing from the matrix.
- Lookup-backed Country / Language / Skill definitions rendered as a free-text "enter option ID" box.
- DateTime submitted a bare `yyyy-mm-dd` rather than ISO-8601.
- Inverted `Between` ranges reached the server and 400'd.
- The `customFields` query param was double-encoded.
- The clause objects reached `FilterBadges`, which crashed with
  _"Objects are not valid as a React child"_ as soon as a filter was applied.
- Nothing was wired on the admin page.
