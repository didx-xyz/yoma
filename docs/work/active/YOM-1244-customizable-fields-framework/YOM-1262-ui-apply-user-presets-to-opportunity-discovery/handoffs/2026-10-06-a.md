## What Was Done

Jason's four items:

1. **Search without my preferences no longer wipes type-specific filters** (the logic wave).
   Jason's rule: a type's filters leave with that type, and filters on types still in effect stay.
   - **Applied on every path where types shrink:**
     - the type row, a chip ×, a quick search, the type popover's reset;
     - skipping the Goal, and the preferences switch;
     - every preference save: the wizard, "Make this my default" and undo, and "Keep answers".
   - **Filters are matched to types** by each definition's `entityContext`, read from the
     definition lists React Query already holds. Generic definitions stay while any type
     remains. Unknown attribution falls back to the old clear-all.
   - **A save is one action** (`preferencesSaved`), and the provider holds the old preferences
     until the save's push renders.
   - **A dispatch that changes nothing doesn't push.**
   - **A dispatch after the provider unmounts is ignored.**

   five places. Round badges widen to pills for two digits.
3. **The wizard's "Skip this" is gone.** It called the same action as Continue.

## Gotchas

- **`reduceDiscovery` needs a `ClauseAttribution`.** A new dispatch site goes through the
  context's `dispatch` (it supplies one). A new preference save must go through
  `savePreferences`, or the old Goal's filters stay and the held-preset protection is lost.
- **Only the provider may dispatch from an effect.** A child effect that dispatches on mount
  breaks `settlePushes`' ordering, and is dropped in dev under StrictMode.
- **Filter-to-type matching reads the React Query cache** (`opportunityCustomFieldDefinitions`
  lists). If that query key or its shape changes, attribution falls back to clear-all, silently.
- **The detail title measures before paint** (`useLayoutEffect`). The grid row must stay
  `min-content`, or every md+ card grows.
