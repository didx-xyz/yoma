## Gotchas

- **The local Maps key allows only `http://localhost:3000/*`.** Any other port fails with
  `gm_authFailure`. It needs **Places API (New)**, **Geocoding API** and **Maps JavaScript API**
  in its API restrictions (all three were set on 2026-09-28).
- **Reverse geocoding cannot use the REST endpoint** with this referrer-restricted key ("API keys
  with referer restrictions cannot be used with this API"). It has to go through
  `google.maps.Geocoder`.
- **The suggestion text is in the language the youth typed**; the resolved place is in English.
  Never store `prediction.text`.
- **`LocationInput` renders "Use my location" only once Maps has loaded.** In automated passes,
  wait for the button before clicking it.
- **The lookup's "Worldwide" (`COUNTRY_CODE_WW`) is a filter value, not a place.** It is
  excluded from the wizard's country picker and never unlocks region / city.
- **Headless passes while `next dev` owns :3000:** drive Chrome over CDP against the dev server.
  To load a test page on the key's allowed origin without touching the server, fulfil a
  `http://localhost:3000/<test>.html` request with `Fetch.fulfillRequest`. Node 24 is needed for
  the global `WebSocket` (`mise x node@24 --`); outside the repo, `mise x` picks Node 20.
- **Where sections start expanded when a country is selected** — clicking the header in a
  script collapses it.
