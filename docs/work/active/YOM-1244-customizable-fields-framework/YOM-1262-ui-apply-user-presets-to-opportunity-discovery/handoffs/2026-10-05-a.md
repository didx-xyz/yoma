## Reviewer findings

Every finding was fixed in the round named, unless marked otherwise.

- **W1, round 1: three bugs.**
  1. **A blur commit raced the tap that caused it.** Tapping a type, or a react-select clear,
     right after typing lost one of the two changes. Discovery's dispatch reduced from a stale
     `router.query`. Fixed at three levels: `reduceFromLatest`, the `setCustomFieldClauses`
     reducer action, and `setFilter` building on its last emission.
  2. **Clear filters left a stale invalid draft on screen.** Fixed through a reset key, later
     `resetEpoch`.
  3. **Unparseable number input (`5000e`) silently removed the clause.** It now tracks
     `validity.badInput` and shows the error.

  Nits taken: an accessible name on the fixed-mode multi-selects; the height; an "Any of"
  prefix for non-Option old links; unknown operators dropped on parse.
- **W1, round 2: no bugs.**
  - Taken: an invalid draft no longer vanishes when the tap that blurred it changes another
    filter; typing right after Enter is no longer overwritten.
  - **Left, contrived:**
    - an async handler's stale `dispatch` combined with Back can build on an undone push
      (`PreferenceBanner` save/undo, `PersonalizeDialog`);
    - `setFilter` composes on array identity, so an unrelated render inside the window
      defeats it.
- **W1, round 3 review: no bugs.** For the record:
  - an invalid draft survives a type deselect when its own clause was already empty;
  - `settlePushes` assumes no child effect dispatches in the same commit as a replaced render
    (none does today);
  - after Enter, an error shows live while typing continues.
- **W2, round 1: two bugs.**
  1. The editor Preview's "marketplace" link would navigate away and lose the unsaved draft.
     It is now a span in preview.
  2. Migrated ZLTO opportunities (with `incentivized` null) showed "hasn't said whether this
     pays or rewards". Jason ruled that a stored reward counts.

  Also taken: the offline guard in `isCashOutClosed`; G2 `px-2`; a defensive wrap for long pay
  lines in the list row; the comments that claimed the money strings never disagree.
- **W2, round 2: no bugs.** Taken: a Job's disclosed salary counts as a stored reward; the
  admin stat strip matches the fact strip below 360.
- **W2, round 3 review: no bugs, no nits.**

## Gotchas

- **Discovery dispatches now compose.** Anything computed in the reducer builds on the last
  push until a new query renders. A patch built from render state (`patchFilters`) still
  overwrites a same-facet patch in the same window, as before. A new effect that dispatches
  inside a child of the provider breaks `settlePushes`' ordering assumption.
- **`resetEpoch` is the "search replaced" signal.** Use it for UI state that must reset on Clear
  filters or back/forward, but not on an ordinary edit.
- **`commitOnBlur` does nothing without `fixedOperators`.**
- **Signed-in detail pages write a "Viewed" record.** For a no-change pass, don't open them
  signed in.
- **The sticky bar's ZLTO pill reads `zltoReward`; the header and Incentive read
  `zltoRewardEstimate`.** They differ when the pool runs low. This predates the round.
