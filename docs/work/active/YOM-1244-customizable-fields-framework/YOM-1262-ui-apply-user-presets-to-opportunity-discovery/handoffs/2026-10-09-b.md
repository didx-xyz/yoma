## Gotchas

- **`detailBadges.ts` must not import `.tsx`.** node:test can't load it, so the component passes
  in the effort and engagement labels.
- **Tone classes are spelt out per tone** in `DetailFactBadges.tsx`, `md:` variants included.
  A class built at runtime (`md:${tone}`) is never generated.
- **Relative dates render after mount** (`now` is set in an effect); until then the badge shows
  the absolute date. Don't compute "N days left" during render from `new Date()`.
- **Apostrophes in JSX text need `&apos;`** (`react/no-unescaped-entities`). A scripted copy
  change should run ESLint straight after.
