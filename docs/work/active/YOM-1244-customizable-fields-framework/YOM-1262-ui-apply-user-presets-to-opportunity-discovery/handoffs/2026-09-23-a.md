## Gotchas

- **The type-specific filters block is empty on Local and DEV, and that is data, not code.** The
  consolidated migration `20260915100000_…_Custom_Fields_Treasury_Payout_SSI` has the
  `SeedCustomFields(…)` call commented out (cash-out-first release, PR #1924), so any database
  rebuilt on the new sequence — the local one already serves the 16-category taxonomy, so it was —
  has zero rows in `Core.CustomFieldDefinition` / `CustomFieldOption`. DEV returns 200 with `[]`
  too. The block, its hook and its gate are unchanged by this session; with definitions present
  it renders as before. Check the endpoint before suspecting the web.

- **The engagement null rule is inverted between BA and API.** BA: hide Not specified while set.
  API (`OpportunityService`, engagementTypes filter): `!o.EngagementTypeId.HasValue || …` includes
  them. Server-side paging means web cannot fix this client-side; the copy says "includes … for
  now". Do not "fix" it in the request builder.
- **"Closed" on every card is the fixture, not the rule.** Local seeds all end 2026-09-21 and DEV's
  all end 2026-09-23 while status stays Active because the search's Active published state ignores
  `DateEnd` and the expiry job has not run. Set a future end date on one opportunity to see the
  open states.
- **Category facet counts are grand totals on DEV too** (~1 000 per category) — every seeded
  opportunity carries every category. Not a bug in the tiles.
- **`mise` must wrap the tooling.** A bare shell here picks up Node 20 and pnpm 11 refuses it; run
  `mise x -- pnpm exec …` or activate mise. The puppeteer archives in `~/.cache/puppeteer` are
  truncated (an aborted install) and cannot be extracted.
- **`goal` is no longer in `PREF_GROUPS`.** Its chip group comes from the fragment's facet; if you
  add a preference whose fragment can be more than one facet, leave it out of `PREF_GROUPS` too.
- **ZLTO hidden while Job is selected does not clear an already-set ZLTO filter** — it stays in
  the applied chips, removable there. Decision was hide, not grey; revisit if the mixed-type case
  confuses testers.
- **The Where reserved inputs and the Provider typeahead are new control kinds** (`reserved` data
  on the section; `typeahead` and `rewards` kinds). The registry abstraction held for everything
  else in this pass — those three needed JSX.
