## Gotchas

- **A rail's See all must rebuild its exact page-1 request.** Place rails are
  `manualSearch(place + filter)`, and their See all carries `prefsOff=1`, so the destination
  composes the same search. Change one side and `landingRails.test.ts` fails. Keep it that way:
  that is what makes the results page open from cache.
- **Rail keys include the search** (`id|JSON(search)`), so a skip remounts the rail on its new
  query, and `keepPreviousData` never shows the old cards.
- **A collapsed rail is a zero-height sentinel with a negative top margin.** It cancels the
  landing's `gap-8 md:gap-10`. Change that gap and you must change the margin.
- **`useInView` is a callback ref** and latches on the first sighting. A section's element can
  change from the rail to the sentinel.
- **`closingInfo` counts calendar days for its labels, but "Closed" is the instant.** Anything
  server-rendered must not call it with a server clock: see the detail page's after-mount `now`.
- **`CustomCarouselV3` is shared with the legacy `/opportunities` page.** Its new options are
  additive; callers that pass none get today's behaviour, except a reduced-motion snap.
