## Gotchas

- **Rows keep local state.** A row is `{id, key}`. Clauses set elsewhere get a synthetic row
  (`set-<key>`) until a local row takes that key. Don't key rows on the clause, or the value
  control remounts on its first commit and loses focus.
- **The bar's outside-click check skips `[id^="react-select-"]`.** Any other portalled menu in a
  WHAT popover needs the same treatment.
- **My CDP helper scrolls a target into view before clicking**, which moves the dialog under a
  portalled menu, so a click on a lower option can miss. A real click doesn't. Use the keyboard
  (type, then Enter) for those in scripted passes.
