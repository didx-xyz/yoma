## Gotchas

- **Section bodies must not mount on load.** `DetailDisclosure` mounts its children on first open
  (`everOpened`). Always-mounted bodies fire `CustomFieldsView`'s lookup queries for every visitor.
- **Shown bars use `translate-none`, never `translate-y-0`.** Any `translate` value other than
  `none` makes the bar the containing block for `position: fixed` children, such as the admin
  `<Loading/>` overlay.
- **Tailwind v4 animates `translate`, `scale` and `rotate` as their own CSS properties.** A
  transition list must name them (`transition-[opacity,translate]`); `transform` does nothing.
- **MDXEditor's CSS is unlayered.** The description's font, colour and padding overrides need `!`.
- **`featured` reads only `featured=1`.** Any other value is unset, because the API filters only
  on `true`. No preference ever supplies it.
- **Lone cards don't span: Jason vetoed it, and it was reverted before the commit.** A group's
  only card fills the left cell, as the brief has it, so on a Job page the right half of Time
  needed, Countries, Topics and Additional details stays empty at `lg`. That is intended. Only the
  description and the admin Rewards block span both columns.
- **There are no classic before-screens**, because every capture runs with the kill-switch on.
  Classic was judged by its code (token-identical to `31dabdbc`) and the one flip.
- **Seen, predating this round, not changed:**
  - the "Help us improve Yoma!" prompt swallows the first click and peeks under the welcome at
    1440;
  - the welcome dialog is non-modal (2026-09-03). Since F4, focus starts on Get started, but Tab
    can still leave the dialog;
  - the site navbar is clipped at 768;
  - at the bottom of the page on 390, scroll-spy can light a tab outside the visible pinned bar.
- **`master` is squash-merged.** `f176f51d` and `31dabdbc` are cited here and in `design/`;
  re-point or annotate them before the PR lands.
