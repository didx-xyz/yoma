## Gotchas

- A retained A/B swap has no valid first individual update; reversing processing order merely changes which task collides. Batching `SaveChangesAsync` alone is not the fix.
- The clearing phase is safe only within the caller's transaction. A guard enforces an ambient transaction for retained assignment reconciliation. Never persist temporary nulls independently or relax the index.
- Persisted assignment snapshots are read for each attempt because the domain pathway object may already reflect a rolled-back attempt. The central opt-in handles EF tracking state.
- PostgreSQL tests require `YOMA_REFERRAL_PATHWAY_TEST_CONNECTION`, a localhost host and a database named `yoma_referral_pathway_*`. They use minimal test tables plus the actual task repository, transaction and execution strategy; other programme dependencies are mocked. No live API smoke test was performed.
