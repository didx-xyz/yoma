## Gotchas

- `mvn clean install` rewrites every tracked JAR in `src/keycloak/providers/jars/` even when its source is unchanged, because zip timestamps change. Diff the extracted contents, not the bytes, before deciding what to commit.
- The JDK `jar` tool is not on the mise shim path outside the repo directory. Use `$(mise where java)/bin/jar` (the shell has no `unzip`).
- A fake Twilio `Response` needs non-null headers (`new Response(body, status, new Header[0])`). Otherwise the SDK throws an NPE, which the sender's catch-all reports as a send failure and which looks like a real fallback.
- Concurrent sends and failed-send throttling are still open, as the brief says. This fix does not change them.
