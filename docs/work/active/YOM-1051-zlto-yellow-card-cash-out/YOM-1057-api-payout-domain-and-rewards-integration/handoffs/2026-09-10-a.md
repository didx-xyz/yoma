## Gotchas

- Processing does not mean youth confirmation or bank delivery. It starts at hosted-payout creation.
- CanResume is eligibility to request a session, not a promise of provider availability.
- A session 404 alone cannot establish a terminal outcome; refetch profile.
- Latest status remains visible after active becomes false; never turn that into completed-session resume.
- Preserve USD vs ZLTO labels; no existing field was renamed.
- The normal dotnet test VSTest path rejects this .NET 10/Microsoft.Testing.Platform combination.
  Run the built xUnit executable without changing repository test configuration:
  `dotnet test/Yoma.Core.Test/bin/Debug/net10.0/Yoma.Core.Test.dll -filterVSTest 'FullyQualifiedName~PayoutYouthContractTests' -noLogo`.
  Build first with `dotnet build test/Yoma.Core.Test/Yoma.Core.Test.csproj --no-restore` from src/api/src.
