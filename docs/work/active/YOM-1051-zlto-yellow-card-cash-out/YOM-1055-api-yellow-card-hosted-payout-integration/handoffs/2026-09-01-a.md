## Gotchas

- Country availability is provider-owned and dynamic; never hardcode the current 18-country list.
- The resolved provider-country list is request-driven and cached per API instance using the existing
  application-wide lookup-cache expiry settings. It refreshes only when requested after expiry.
- An expected provider HTTP failure returns an offline result with no country list rather than breaking
  the complete profile. The standalone country endpoint returns HTTP 503, the profile returns
  `CountryAvailability.Supported = false` and `CountryAvailability.Offline = true`, and payout initiation
  remains fail-closed before any reservation.
- The hosted provider still enforces real-time channel availability. Yoma validates only before
  initiation and never blocks reconciliation of an active payout.
